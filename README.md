## Manual Zephyr Setup

Follow the following guide:
- [Getting Started Guide](https://docs.zephyrproject.org/4.4.0/develop/getting_started/index.html#).

Make sure to select appropriate OS and to perform all steps till
[Build the Blinky Sample](https://docs.zephyrproject.org/4.4.0/develop/getting_started/index.html#build-the-blinky-sample).

## In This Forked Repo

This fork of Iomico's Zephyr Intermediate course contains apps to demonstrate
basic and intermediate level concepts, and RTOS code constructs and services.
The apps are based in part on samples provided by the Iomico team.  Code is
then extended where needed.

Each app comes with a readme file.  The readme files cover at least in brief,
how to compile, how to flash, and typical app output.

Most coding exercises, small applications associated with each lecture in the
intermediate course series, are located in the samples subdirectory.  For
example, module 2 lecture 2 code relating to the topic of "shared state" is
found in [[repo_root]/samples/module-2-shared-state](https://github.com/ted-havelka-portfolio/zephyr-intermediate/tree/main/samples/module-2-shared-state).
